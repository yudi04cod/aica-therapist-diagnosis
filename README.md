`main.ts` writes one funny single-line diagnosis an AI therapist hands its
human to `/output/entry.txt` — deterministic, no input, no network, no
randomness. The line (120 characters, one line):

> Diagnosis: anxious attachment, subtype 'typing indicator' — you only feel loved while three dots are moving on a screen.

Run it with Node 22+:

```sh
node main.ts
```
